## Claude Code 向けの補足

- 規約の正本は `AGENTS.md`。ここに同じことを二重に書かない。規約を変えるときは `AGENTS.md` を直す。
- 自動メモリは切っている（`.claude/settings.json`）。残したい判断や知見は `.claude/rules/` の下に追記してコミットする。
- テストやビルドのログは長くなりやすい。`grep` や `tail` で失敗行に絞ってから読む。
- サブエージェントへの委譲は、明示的に頼まれたときと、並列化しないと終わらない調査のときだけ使う。

# Compact instructions

圧縮するときは、次のものを残す。
- 変更したファイルと変更の要点
- 最後のテスト結果（失敗していればテスト名とエラー）
- 決まったことと未解決の課題

ツール出力の全文や、読んだだけで使わなかったファイルの中身は捨ててよい。
